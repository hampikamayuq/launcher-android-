# Screenshots

Ainda não existem screenshots — este `.gitkeep` mantém a pasta no Git até que
alguém tire e adicione as imagens. Quando forem feitas:

- PNG ou JPEG, 2–8 imagens, lado mais curto entre 320 px e 3840 px (o mínimo
  de qualquer loja que as consuma; F-Droid e Play aceitam a mesma faixa).
- Nomeie em ordem de exibição: `1.png`, `2.png`, `3.png`, ...
- Prefira capturar num aparelho com poucos apps de sistema visíveis, para a
  lista não ficar poluída, e num tema (claro/escuro) neutro.
- Conteúdo sugerido — as telas mais visuais do plano (`docs/plano.md`,
  Fase 9): lista alfabética com índice lateral (Fase 1), cards de "at a
  glance" com clima ligado, edição `full` (Fase 3), notificação expandida na
  lista (Fase 4) e a área de widgets em pilha (Fase 5).
- Esta pasta é a padrão/fallback (`en-US`); screenshots específicos de
  `pt-BR` ou `es-ES` são opcionais — sem eles, F-Droid e o fastlane usam os
  daqui.

Depois de adicionar as imagens, apague este README (o `.gitkeep` também pode
sair, já que a pasta deixa de ficar vazia).
